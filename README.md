# 🎲 Jogo do Número Secreto

> Um jogo interativo e divertido em JavaScript, HTML e CSS onde o jogador deve adivinhar um número secreto gerado aleatoriamente pelo sistema.

---

## 📌 Sobre o Projeto: 

> O **Jogo do Número Secreto** é uma aplicação web simples e interativa criada para praticar manipulação de DOM, condicionais, funções e lógica de programação em JavaScript. O jogo dá dicas ao jogador informando se o número secreto é maior ou menor a cada tentativa, contabilizando as chances até a vitória.

---

## ✨ Funcionalidades:

- [x] **Geração Aleatória:** O sistema gera um múmero secreto a cada nova partida.
- [x] **Dicas em Tempo Real:** Informa se o número secreto é maior ou menor que a tentativa inserida.
- [x] **Contador de Tentativas:** Exibe a quantidade exata de tentativas necessárias para acertar.
- [x] **Reinício do Jogo:** Botão interativo para reiniciar a partida com um novo número secreto sem precisar recarregar a página.

---

## 🛠️ Tecnologias Utilizadas:

- **JavaScript (ES6+):** Lógica do jogo e manipulação do DOM.
- **HTML5:** Estrutura da interface do usuário.
- **CSS3:** Estilização e layout da aplicação.
- **Git e GitHub:** Controle de versão e repositório.
